# Craft floor and responsive checks

Use this table during build, polish, audit, and harden. DET means the browser probe can measure a signal; JUDG requires a reviewer to decide whether the design intent supports it. A machine finding carries its actual value, threshold, viewport, and claim tier. Only a confirmed HIGH finding blocks completion. Browser-only measurements stay not verified when the browser is unavailable. Keep the threshold data in `scripts/probe-rules.json` aligned with these rules.

The responsive pass runs at 320, 390, 768, and 1440 CSS pixels in light mode; repeat 390 in dark and reduced-motion modes, then emulate 200% zoom with a 720×450 viewport. The emulation proves reflow, not browser text rasterization. Record screenshots for every pass.

| Rule | Check | Floor or decision | Method | Severity |
| --- | --- | --- | --- | --- |
| CF-101 | Body-text measure (characters per rendered line) | Target 60–75 chars/line (Latin) and 30–45 (CJK-majority, meaning >30% Hangul/CJK code points). A finding (MEDIUM) is raised only when a prose block renders ≥2 lines and its longest line exceeds 90 chars (Latin, the plan's "fail above 90") or 60 chars (CJK). A single-line block never fires (Delta 1; supersedes Conflicts resolved #10's "no 90ch hard-FAIL") | DET | MEDIUM throughout, never HIGH (see calibration: the check over-fires on non-prose containers, and the Latin-glyph ch proxy is not a validated fit for CJK-majority copy) |
| CF-102 | Heading line-height | 1.2–1.35 for a normal heading role; a large display/hero heading (≥40–48px) may run as tight as 1.05, exempt from the 1.2 floor (see Conflicts resolved #1) | DET | MEDIUM, only once the heading element itself renders ≥2 visual lines |
| CF-103 | Body line-height | A finding (MEDIUM) is raised when a ≥2-line body block is below 1.4 (Latin) or 1.5 (CJK-majority). 1.5 Latin and 1.6 CJK remain the recommended targets and raise nothing. No upper bound (Delta 1; the calibrated DET floor was 1.4, and 1.5/1.6 were never calibrated as fail lines — see Conflicts resolved #2) | DET | below floor: MEDIUM |
| CF-104 | Wrapped-row line-height floor | ≥1.4 whenever a column can wrap to 3+ lines, even in a dense layout | DET | MEDIUM |
| CF-105 | Balanced headings, no stranded last word | Heading uses a balancing wrap mode (sourced, DET); body avoids an orphaned short last line (unsourced numeric proxy, JUDG) | DET (wrap-mode presence); JUDG (orphan call) | LOW |
| CF-106 | Tabular figures for aligned/updating numbers | Any numeric table column, KPI, or in-place-updating number uses tabular figures | DET | LOW–MEDIUM |
| CF-107 | Sentence case for UI labels | Button, nav, and form-control labels use sentence case, not Title Case | DET | LOW |
| CF-108 | Type-role and family ceiling | ≤7 named type roles; ≤2 body/display families + 1 mono, a 3rd family needs a recorded exception | DET census, JUDG verdict | MEDIUM if exceeded with no recorded exception |
| CF-109 | Weight floor by size | Below 18px stay at weight ≥400; weights 100–300 are display-only at ≥28px | DET | MEDIUM |
| CF-201 | WCAG contrast floor | Body/small text 4.5:1; text ≥24px (or ≥18.5px bold, per krehel contrast.md's 14pt≈18.5px rounding — not 19px) and UI-component boundaries/icons/focus rings 3:1. Text inside a disabled control (:disabled, aria-disabled="true") is skipped, per WCAG 1.4.3's inactive-component exception. Placeholder contrast is owned by CF-807 alone | DET | body below floor: HIGH; large-text/component tier below floor: MEDIUM |
| CF-202 | Focus-indicator thickness and contrast | Focused and unfocused computed styles must differ in at least one of outline, box-shadow, border or background-color. Read them only after el.matches(':focus-visible') is confirmed true; if it is false, report not_verified. A computed outline-style: auto is the browser's own two-tone ring and passes the thickness and contrast checks outright, because its computed outline-width (1px) is not its painted width. A custom ring should be ≥2px and ≥3:1 against the resolved background just outside it | DET | HIGH only when nothing changes on focus (no visible indicator, MD-011 #2); MEDIUM when a custom ring exists but is under 2px or under 3:1 |
| CF-203 | APCA advisory layer | Body Lc 75 min / 90 preferred; non-body Lc 60/75; large (≥36px) Lc 45/60; UI components Lc 30 floor | DET computation, JUDG weight (advisory, never blocks alone) | informational annotation on a CF-201 finding |
| CF-204 | Contrast against an image or gradient background | Sampled worst-case region must still clear CF-201's floor | DET (derived for a CSS gradient; an image only through the optional same-origin canvas upgrade, else not_verified) | HIGH if the sampled region fails |
| CF-205 | One accent colour per view | At most one high-saturation hue used for interactive emphasis in a single rendered view | JUDG with DET-assist histogram | MEDIUM |
| CF-206 | Hue tolerance for "one meaning" | Two accent/status hues within 15° of each other count as the same semantic colour | DET | LOW |
| CF-207 | Status never carried by colour alone | A state/status indicator pairs colour with text, icon, or pattern | JUDG with DET-assist | HIGH (auto-HIGH) |
| CF-301 | On-scale spacing | A computed padding, gap or margin value is on-scale when it is within ±1px of a multiple of 4px. Values under 4px (hairline adjustments) are skipped, and so are equal (±1px) left and right margins on a block narrower than its parent, since those are resolved margin: auto | DET | 1–3 distinct off-scale values in a view: LOW; more than 3: MEDIUM |
| CF-302 | Grouping ratio | Inter-group gap ≥2× intra-group gap | DET | MEDIUM |
| CF-303 | Adjacent-element breathing room (non-interactive visual grouping) | ≥12px between bordered/filled visual blocks; ≥24px around borderless blocks and between unrelated groups — scoped to non-interactive grouping/whitespace rhythm | DET | MEDIUM |
| CF-304 | Heading spacing asymmetry | Target: more space above a heading than below it (≈2× per current composition.md). DET fail line: a clear inversion only — above < 0.75× below AND below − above ≥12px; equal spacing is not flagged | DET | LOW |
| CF-305 | Full-width control inset | A full-width primary control stays inset from the viewport edge (≈16px), not flush | DET | LOW |
| CF-306 | Prefer container gap over sibling margins | A repeated group's rhythm comes from the parent's gap, not per-child margin | JUDG | LOW |
| CF-401 | Concentric radius | Inner radius ≈ outer radius − padding, tolerance ±2px (Delta 1 adopts §C.3's gating; see the corrected Conflicts resolved #5). Both radii are capped at min(width, height)/2 before comparing; the pair is compared only where the child's box reaches the parent corner being compared; skipped once the parent's padding exceeds 24px | DET | LOW |
| CF-402 | Elevation declared once | A surface's border and its own shadow do not duplicate the same edge: flag only a hard, near-zero-blur shadow (≤2px) tracing the same boundary a border already draws (the "ghost card" pattern), not any border-plus-soft-shadow pairing | DET | LOW |
| CF-403 | No hard offset shadow outside a declared register | box-shadow with ≈zero blur and a large solid offset is banned unless the page's recorded visual register explicitly calls for it | JUDG (register-dependent) | MEDIUM |
| CF-404 | No glow/bloom on primary actions | One glow test shared with SLOP-010: a box-shadow/filter: drop-shadow with offset ≤2px, blur ≥16px and shadow HSL saturation >0.4 (the earlier "1.5× shorter side" test is dropped). Each glowing element is reported once: under SLOP-010 when the same glow recurs on ≥2 unrelated elements, otherwise here at LOW (a single glowing heading is also reported here, per that split) | DET | LOW |
| CF-405 | Neutral image outline | A ~1px low-opacity, near-achromatic outline around photographic imagery | DET | LOW |
| CF-406 | Solid modal scrim | A modal backdrop is solid or near-solid, not backdrop-filter: blur | DET | LOW |
| CF-407 | Undecided decorative patterns | A grid/dot background, radial halo, marquee, or pseudo-element stripe with no real content referent | DET presence, JUDG "real referent" | LOW–MEDIUM |
| CF-501 | Named token set kept | enter 420ms cubic-bezier(0.16,1,0.3,1); ui 180ms cubic-bezier(0.2,0.8,0.2,1); exit 160ms cubic-bezier(0.4,0,1,1) | DET | LOW (drift from the set) |
| CF-502 | Press feedback | Scale to 0.96 over 150ms, ease-out; never below 0.95 | DET | LOW |
| CF-503 | Entrance scale floor | An entrance transform never starts at scale(0); it starts at ≥0.95 — this floor does not apply to an icon-swap cross-fade, which follows its own transition instead | DET | MEDIUM |
| CF-504 | Exit shorter than entrance, same path reversed | Exit duration < entrance duration; same movement axis, reversed | DET | LOW |
| CF-505 | No spring bounce on feedback motion | Overshoot/bounce stays at 0 for toggle/toast/press feedback | DET where a curve is inspectable, else JUDG from a recording | MEDIUM |
| CF-506 | High-frequency interaction ceiling | A routinely-repeated interaction stays ≤150ms or instant | DET | LOW |
| CF-507 | will-change restricted | Only transform/opacity/filter, only while the animation is running | DET | wrong property: LOW; left on at rest: MEDIUM |
| CF-508 | No layout-triggering continuous animation | width/height/padding/margin are not animated continuously; transform/opacity are used instead, except a deliberate scoped all | DET | MEDIUM |
| CF-509 | Reduced-motion path stays functional | Every motion-gated state, label, and control stays reachable with prefers-reduced-motion: reduce forced | DET (media query applies), JUDG (meaning preserved) | HIGH if a control/state becomes unreachable |
| CF-510 | Slow-motion replay check before sign-off | No numeric threshold — a checklist judgment call | JUDG | LOW |
| CF-601 | Single-system stroke discipline | One grid (24px), one stroke weight per icon set; a set that ships weight variants may match a variant to adjacent text weight (regular↔lighter, semibold/bold↔heavier) | JUDG (system-level) | MEDIUM if two unrelated icon families appear on one surface |
| CF-602 | Icon-to-text relative sizing | Icon ≈1–1.25× adjacent text's cap-height; legible at a 16px minimum render | DET | LOW |
| CF-603 | Icon-only controls stay named and never solo on a destructive action | Every focusable control (button, a[href], input, select, textarea, [role=button\ | link\ | checkbox\ |
| CF-604 | Optical alignment over bounding-box alignment | Icon-side padding runs ≈2px tighter than text-side padding in the same control | JUDG | LOW |
| CF-701 | Hit-area floor and recommendation | Coarse pointer ≥44×44px recommended; 24×24px is the WCAG 2.5.8 AA floor: a target below it fails unless WCAG 2.5.8's spacing exception holds (a 24px-diameter circle centred on the target's box intersects no other target's box or circle). Touch-primary is decided by viewport width, not the pointer media feature (emulated viewports leave (pointer: coarse) false): widths ≤768 (320, 390, 768 and the 720 zoom pass) are touch-primary, 1440 is fine-pointer. On a touch-primary width, 24–44px is MEDIUM for a non-primary control (never a silent pass) and HIGH for a primary action — the form's sole type=submit button, or the first filled button or button-styled link inside the first viewport (a narrower, fully mechanical form of the heuristic §C.3's CF-404 row uses); at 1440 a 24×24px target passes. The same width rule governs CF-702, CF-703 and RS-008 | DET | below 24px without the spacing exception: HIGH (FAIL); 24–44px primary action on a touch-primary width: HIGH; 24–44px non-primary on a touch-primary width: MEDIUM; 24–44px at 1440: pass |
| CF-702 | Neighbour clearance by pointer class | ≥8px clear space between coarse-pointer targets' expanded areas; ≥4px for fine-pointer | DET | MEDIUM |
| CF-703 | Destructive controls keep the coarse minimum everywhere | 44×44px floor applies to a destructive control even on a fine-pointer surface (the 1440 width, per CF-701's width rule) | DET | HIGH if violated |
| CF-704 | Hover/drag-only actions expose a discrete alternate control | Any action reachable only by hover, drag, or long-press also has a tap/keyboard-reachable equivalent | DET (stylesheet scan), else JUDG | HIGH (auto-HIGH: pointer-only-reachable control) |
| CF-801 | Verb-first, plain-word action labels | A button/action label leads with a verb and avoids jargon | JUDG | LOW–MEDIUM |
| CF-802 | Tone calibrated by stakes | Warm for success/onboarding/empty; neutral for routine/settings; calm for errors/destructive; serious for data-loss/security | JUDG | checklist item |
| CF-803 | Errors name what happened and how to recover | A vague denylisted phrase with no further detail fails | DET assist + JUDG | MEDIUM |
| CF-804 | One capitalization policy | Sentence case throughout, or a documented exception list | DET | LOW |
| CF-805 | Toggle labels state the ON condition | A setting label describes what turns on, not a bare noun | JUDG | checklist item |
| CF-806 | Placeholders are examples, never the only label | A real <label>/aria-label exists beside any placeholder; no bracket-instruction placeholder text | DET | MEDIUM (label-only-via-placeholder is also an accessibility escalation) |
| CF-807 | Placeholder contrast meets the same floor | ≥4.5:1 against the field's own background (cross-ref CF-201) | DET where the pseudo-element style is inspectable, else not_verified | MEDIUM |
| RS-001 | Canonical probe viewport set | Base pass runs at exactly four widths: 320, 390, 768, 1440px, light scheme, motion enabled | DET | run completeness: a missing width sets exit 2 (§C.5, BLOCKED: matrix incomplete), never a HIGH finding |
| RS-002 | 390px dark-mode pass | Re-run 390px with the dark colour scheme active (real toggle, not a filter) | DET | run completeness: an unrun dark pass sets exit 2 (§C.5), never a HIGH finding and never a silent pass; once the pass ran: MEDIUM when no dark path is found or it adds new HIGH contrast findings (those findings keep CF-201's own severity) |
| RS-003 | Reduced-motion pass | One pass at minimum at 390px with prefers-reduced-motion: reduce forced | DET (query honoured), JUDG (meaning preserved) | HIGH if a control/state becomes unreachable |
| RS-004 | 1440px at 200% zoom emulation | Re-run 1440px at an effective content width of ≈720 CSS px | DET | HIGH if the zoom pass shows page-level overflow (RS-006) or clipped text (RS-007) |
| RS-005 | Content-derived breakpoints | A structural layout change (reflow/stack/collapse/reveal/defer/relocate/freeze) sits at the width real content first breaks, never an unexamined framework default | JUDG, DET-assisted (low-confidence advisory only — see note) | LOW, informational, alongside a finding rather than an equal-weight MEDIUM |
| RS-006 | No page-level horizontal overflow | scrollWidth ≤ innerWidth + 8 at every RS width (the calibrated tolerance §C.2 and MD-011 #14 use; a clean reference overflows by 6px at 320 with no visible defect) (an intentional scroll region needs its own visible affordance, see RS-010) | DET | HIGH (auto-HIGH: page-level horizontal scroll) |
| RS-007 | No unintentional clipped/overlapping text | Text is not cut by a clipping ancestor unless a deliberate line-clamp/text-overflow is declared — the declared property alone is a sufficient, self-contained exception and does not itself require a separate "show full text" affordance | DET | clipped or offscreen text: HIGH; overlapping text pairs: MEDIUM (§C.3's split; no probe can classify content as "primary" or "secondary/metadata") |
| RS-008 | Mobile input font-size floor | Text-entry controls render ≥16px on a touch-primary width (≤768: 320, 390, 768 and the 720 zoom pass, per CF-701's width rule), or use a documented compensating-scale technique (which keeps a 16px computed font-size and so passes the same read) | DET | MEDIUM |
| RS-009 | Safe-area-aware offsets | A control fixed to a physical edge adds env(safe-area-inset-*) rather than a bare fixed offset; nothing interactive sits under a notch/home-indicator region. Applies only when <meta name="viewport"> includes viewport-fit=cover (without it the UA keeps content inside the safe area and a bare offset is correct) | DET where the CSS is inspectable, else JUDG from a device screenshot | MEDIUM |
| RS-010 | Horizontal-scroll peek | A scrollable rail with no other visible scroll cue (prev/next controls, pagination dots/tabs, a position counter) reveals 16–32px of the next off-screen item rather than ending flush | DET | LOW |
| RS-011 | RTL pass gated by content | An RTL/bidi mirror check runs only when the brief's real content or shipped locales include an RTL script; logical CSS properties are used throughout so the gated pass is mostly a dir="rtl" toggle | JUDG (the gate), DET (the logical-property audit once gated in) | MEDIUM if a physical-direction property appears where the gate says RTL applies |
| RS-012 | Re-check discipline across states | A finding recorded at one viewport/theme/zoom state is re-sampled at a second state before being reported as a stable pass | JUDG (procedural) | downgrades a lone-state pass to not_verified, not a hard fail |
