# Creative direction

Choose a visual direction that supports the task and existing product. Do not run a direction exercise when the user has already chosen one.

## Archetypes as starting points

Select a host archetype, then adapt it to actual content. Each has a tradeoff to test.

| Archetype | Useful when | Risk to check |
| --- | --- | --- |
| Restrained instrument | Stable, task-focused operation | Can feel unfinished without a distinct anchor |
| Print editorial | Reading and narrative matter | Can fail at high data density |
| Wireframe candor | Precision and alignment matter | Overlays may lack separation |
| Stacked material | Grouping by elevation helps | Cards can become equally loud |
| Poster contrast | A short, decisive action matters | Glare and overused accents |
| Terminal density | Expert operators scan repeated data | New and low-vision users can be excluded |
| Atmospheric ground | A visual field supports the content | Contrast and media weight |
| Motif system | One recognizable mark can unify surfaces | Repetition can compete with the data |

Two archetypes can coexist only with a clear host. Let the host govern composition, density, and depth; borrow at most two named traits from one donor. Record the borrow so it does not spread unnoticed.

## Record the chosen direction

Before tokens or components, state the host, any donor traits, the task-specific visual anchor, type and color roles, depth and density, motion/accessibility tradeoffs, three explicit refusals, and the cost of reversing it. Keep the record short enough to update when the implementation changes.

## Test it against its risks

- Compare the direction with the actual product and content, not a competitor's signature.
- Check the densest real screen, plus empty and error states.
- Check supported viewports, zoom, and longest or CJK text where applicable.
- Verify that the memorable element does not obscure task hierarchy or access.

Classify visual references using the rules in brand-and-imagery.md. If replacing the referenced wordmark with neutral text still makes the page unmistakably look like that product, revisit the direction.

## Keep options bounded

If the direction is genuinely undecided, present a small set of distinct options, each with who it serves, its main tradeoff, and reversal cost. Mark the selected and rejected choices in the task record. Do not call several materially different directions “acceptable” and proceed as if one were chosen.
