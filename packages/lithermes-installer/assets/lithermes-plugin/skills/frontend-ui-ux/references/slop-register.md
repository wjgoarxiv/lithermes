# Slop register

Scan the rendered surface before making a taste judgment. DET rows are observable signals; a JUDG or DET-assist row is a prompt for a reviewer, never an automatic verdict. Fix the underlying repetition, empty decoration, or fake content in the cheapest order: delete, use the platform, reuse an existing design value, correct the value, then add. A brand rationale or real data binding may make a visual signal intentional; record that evidence rather than suppressing the signal.

| Rule | Signal | Method | Threshold | Severity | Cheapest relevant fix |
| --- | --- | --- | --- | --- | --- |
| SLOP-001 | Cloned split-hero repetition | DET | run length ≥ 3 consecutive sections | MEDIUM | Break the run with a full-width, stacked, or bento section before the 3rd repeat (correct) |
| SLOP-002 | Identical tile-grid repetition | DET | ≥ 4 identical tiles in one grid, where each tile's child shape is icon/svg/img + heading + text. A grid rendered as ul, ol or table is a data collection and is skipped (Delta 1: the calibrated n ≥ 4 floor; every clean reference has a legitimate 3-item grid) | MEDIUM | Vary tile size/structure per item, or switch one instance to a different layout family (correct) |
| SLOP-003 | Nested card shells / unfilled bento cells | DET-assist, JUDG verdict | nesting depth ≥ 3, or cell count ≠ content-item count | MEDIUM | Collapse the redundant wrapper, or reshape the grid to match the content count (delete) |
| SLOP-004 | Split-header filler paragraph | DET-assist, JUDG verdict | short column < 15 words, no distinct role, AND JUDG finds no real second message | MEDIUM | Stack headline and body vertically instead of splitting them (correct) |
| SLOP-005 | Layout family reused verbatim across the page | DET | repeat count ≥ 3 (raised from ≥ 2 — reusing one layout family exactly twice on a longer page is ordinary, deliberate design-system consistency; ≥ 3 aligns with SLOP-001's consecutive-run floor) | MEDIUM | Give the repeat's second occurrence a different layout family (correct) |
| SLOP-006 | Monotonous spacing rhythm | DET | page has ≥ 5 distinct visual regions AND ≥ 10 samples, dominant bucket > 85% of samples, ≤ 3 distinct nonzero buckets (raised from > 60% / whole-page sampling — a restrained, intentional 3-token spacing system on a simple page is good practice, not slop) | MEDIUM | Introduce a real multi-step spacing scale and apply it by relationship, not by habit (correct) |
| SLOP-007 | Decorative empty space with no hierarchy role | JUDG | — | LOW (WARN) | Remove the gap or attach it to a real grouping decision (delete) |
| SLOP-008 | Default purple/blue "AI" gradient palette | DET | HSL hue 260°–310° with a channel spread ≥ 50/255, on heading text (h1–h3 or ≥ 20px) or on any gradient stop; brand-consistency exemption applies (Delta 1: the earlier 220°–280° band pulled in ordinary brand blues near 221°–224°) | MEDIUM (calibration: never fired on any of the 19 clean/real pages in this task pack — a narrow single-pattern check, not a validated near-universal tell; downgraded from HIGH) | Swap in a neutral base plus one hue rooted in the actual brand, per the existing lila guardrail (correct) |
| SLOP-009 | Gradient-filled headline text | DET | co-occurrence present | MEDIUM | Replace with a solid color and a weight or size change (correct) |
| SLOP-010 | Glow / bloom halo on primary actions or headings | DET | shared glow test, not a focus state, and the same glow recurring on ≥ 2 unrelated elements | MEDIUM when the same glow recurs on ≥ 2 unrelated elements (Delta 1: a genericness tell is at most MEDIUM); a single glow is reported once under CF-404 (LOW), never twice | Use the shadow-as-border recipe (offset + soft neutral blur) instead, or drop the shadow (correct) |
| SLOP-011 | Floating blob / sphere decoration | DET-assist, JUDG verdict | presence AND JUDG finds no stated purpose (a single deliberate atmospheric blob is a common, often well-regarded accent on modern SaaS marketing pages, not by itself a tell) | MEDIUM | Remove, or tie it to an actual focal point in the layout (delete) |
| SLOP-012 | Decorative dot/grid background with no referent | DET | presence, no adjacent data element, AND ≥ 1 co-occurring slop signal (a dot-grid or blueprint texture alone is a common, tasteful choice on developer-tool sites, not inherently a tell) | MEDIUM | Remove unless the grid is standing in for a real chart (delete) |
| SLOP-013 | Over-rendered noise hiding the layout | JUDG | — | LOW (WARN) | Reduce opacity or remove; if kept, confine it to a fixed non-scrolling layer (correct) |
| SLOP-014 | Glassmorphism used as unexamined default | JUDG | — | LOW (WARN) | Drop the blur for a solid surface unless the brief earns it (delete) |
| SLOP-015 | Fake pseudo-border accent stripe | DET | any one of (a)/(b)/(c) reaching ≥ 2 occurrences in one rounded scope; variant (b) alone reaches threshold at ≥ 1 | MEDIUM | Drop the stripe; carry the same emphasis in the card's own fill or an icon (delete) |
| SLOP-016 | Reflex default sans font | DET-assist, JUDG verdict | any match on the fixed list (Geist family excepted) AND JUDG finds no declared rationale | MEDIUM | Pick a less common face tied to the product's own voice, or state why the common one was kept (correct) |
| SLOP-017 | Serif reached for without a stated reason | DET-assist, JUDG verdict | any match on the shortlist AND no rationale recorded | MEDIUM | Switch to a sans display face, or keep the serif only with a recorded rationale (correct) |
| SLOP-018 | Giant headline over a weak tiny subhead | DET-assist, JUDG verdict | ratio ≥ ~3.5 with subhead below ~14px, AND JUDG confirms it reads as an afterthought | MEDIUM | Raise the subhead's role in the scale or shorten the headline pairing (correct) |
| SLOP-019 | Too many type moods on one page | DET | > 3 distinct families, icon fonts excluded. Chosen over impeccable's stricter 1-family "distill" ceiling because distill is a deliberate reduction workflow, not a general craft floor; krehel's general guidance ("rarely use more than three") is used instead | MEDIUM | Cut back to the stated ceiling for the page (delete) |
| SLOP-020 | Lazy all-caps overuse | DET | leaf text length > ~40 chars under text-transform: uppercase, majority-cased-script text only | LOW | Reserve uppercase for short labels only; sentence-case the rest (correct) |
| SLOP-021 | Washed-out gray secondary text on a colored surface | DET | text L 40–70%, S < 10%, background chromatic | MEDIUM (cross-ref **CF-201** — craft floor owns the canonical contrast-floor check this overlaps; kept here for the reflex-default pattern itself) | Tint the secondary text from the surface's own hue instead of plain gray (correct) |
| SLOP-022 | More than one accent hue competing per screen | JUDG, DET-assist | > 1 accent hue family, fill-surfaces ≥ 24×24px only, status colors excluded | MEDIUM (cross-ref **CF-205** — craft floor owns the canonical one-accent-per-view threshold and the identical filled-surface/status-role-excluded histogram method; this row restates the same finding as a genericness signal, see Section C's CF-205 catalogue entry for the executable algorithm) | Pick one accent per view and demote the rest to neutral (correct) |
| SLOP-023 | Pure black or pure white as a base surface | DET | exact match, outside the declared-dark-theme exception | LOW | Shift to an off-black/off-white a few percent toward the brand's neutral (correct) |
| SLOP-024 | Spring/bounce easing on routine feedback | DET | keyword match, or bezier outside that range, on a routine control | MEDIUM (cross-ref **CF-505** — craft floor owns the canonical threshold and the executable scanAnimationTimingIssues algorithm in Section C; this row is a cross-reference, not a second implementation) | Replace with a settled ease-out curve, or a spring config with bounce fixed at 0 (correct) |
| SLOP-025 | Entrance animation scaling in from zero | DET | scale start ≤ ~0.1 | MEDIUM (cross-ref **CF-503** — craft floor's floor is 0.95, tighter than this row's ~0.1; craft floor owns the canonical threshold) | Start near 0.95, never 0 (correct). Note: an absolutely-positioned icon swap/cross-fade is a distinct convention with its own recipe (scale: 0.25 → 1, never 0.5 or 0.6) — don't fold that case into this general entrance-scale floor |
| SLOP-026 | Animating layout-triggering properties for motion | DET | any layout property present outside the disclosure exception | MEDIUM (cross-ref **CF-508** — craft floor owns the canonical threshold; the slop angle is the reflex choice, not just the cost) | Animate transform/opacity instead (correct) |
| SLOP-027 | Decorative infinite pulse/blink with no bound state | DET | presence, no bound-state signal of any of the above kinds | LOW | Remove, or slow it and bind it to the real status it claims to show (delete) |
| SLOP-028 | Motion fired on every routine, high-frequency interaction | JUDG, DET-assist | transition duration > ~150ms on a selector in the fixed high-frequency set | LOW (cross-ref **CF-506** — craft floor's ≤150ms high-frequency ceiling is the same threshold, scoped to a repeated-selector/scrollable-container gate) | Make the routine case instant or ≤150ms; save longer motion for rare, meaningful moments (correct) |
| SLOP-029 | Eyebrow/kicker label templated above most headings | DET | count > ceil(sectionCount / 3), where sectionCount = the number of visible h2; visible elements only | MEDIUM (Delta 1: a genericness tell is at most MEDIUM) | Drop the eyebrow; the heading and the section's place on the page already carry the context (delete) |
| SLOP-030 | Section numbering used as decoration | DET-assist, JUDG verdict | any match, ≥ 2 distinct index values, AND JUDG finds no real ordering behind it — the ubiquitous "01/02/03 — how it works" pattern describing a genuinely sequential process is not itself a defect | MEDIUM | Remove the numbering; if progression matters, name the step itself instead of counting it (delete) |
| SLOP-031 | Unreleased-looking version/status stamp in marketing copy | DET-assist, JUDG verdict | any match AND JUDG finds no real release-notes context | MEDIUM | Remove the stamp unless the brief is genuinely about a launch/preview status (delete) |
| SLOP-032 | Decorative status dot with no bound state | DET | presence, no bound attribute | LOW | Remove, or reserve it for an actual live/availability signal (delete) |
| SLOP-033 | Middle-dot / locale-time separator strip overused | DET | · count ≥ 3 on one line, OR ≥ 2 co-occurring locale/weather tokens on one line | LOW | Prefer line breaks or columns to chained middle-dots; drop the locale strip unless the brief is genuinely place/time relevant (delete) |
| SLOP-034 | Decorative word strip at the hero's foot | DET | presence within the bottom 15% of the hero's bbox, no <a>/real status content inside, not a compliance-badge strip | MEDIUM | Remove, unless it is a real sticky navigation strip or genuine build/status info (delete) |
| SLOP-035 | Scroll-cue label or arrow at the first viewport | DET | presence | LOW | Remove; a visitor at the top of the page already knows the page continues (delete) |
| SLOP-036 | Marketing buzzword filler | DET | count ≥ 1 | MEDIUM (Delta 1: a genericness tell is at most MEDIUM) | Replace with a specific, product-true claim (correct) |
| SLOP-037 | Fabricated placeholder brand wordmark | DET-assist, JUDG verdict | any match on the fixed list AND JUDG confirms it is not the product's real name | MEDIUM (Delta 1) | Name the product from the brief itself, or invent one name tied to what it actually does (correct) |
| SLOP-038 | Generic placeholder person name (the "Jane Doe" effect) | DET | any match | MEDIUM | Replace with a specific, locale-appropriate name (correct) |
| SLOP-039 | Aphoristic "Not X. Y." cadence repeated | DET | combined count ≥ 3 | LOW | Vary sentence rhythm; keep the device to at most one use per page (correct) |
| SLOP-040 | Em-dash (or flourish en-dash) anywhere in shipped copy | DET | count ≥ 1 in the main scope (zero tolerance unchanged, see Open Question 3); each carve-out hit is reported separately at LOW | MEDIUM (Delta 1: a dash neither blocks nor misleads a visitor; carve-out hits: LOW) | Rewrite with a period, comma, or parentheses instead (correct) |
| SLOP-041 | Fabricated-looking numeric claim | JUDG, DET-assist | ≥ 1 candidate after the exclusions, with no source/mock marker in its block, AND JUDG finds no real origin for it | MEDIUM | Cite the real figure, label it as an example, or cut the number entirely (correct) |
| SLOP-042 | Duplicate call-to-action wording for one intent | JUDG, DET-assist | > 1 distinct label per intent, same page | LOW | Pick one label for that intent and reuse it everywhere on the page (correct) |
| SLOP-043 | Div-built fake product screenshot | DET-assist, JUDG verdict | any of (a)/(b)/(c) with no real-media or focusable descendant, AND JUDG confirms a stand-in rather than a real component preview | MEDIUM once JUDG confirms (tier Inferred, the same posture MD-011 takes for its JUDG items); a DET-assist hit alone is a review candidate, never a finding by itself | Use a real screenshot, a generated image, or a real component preview instead (correct / platform) |
| SLOP-044 | Fake build/version footer inside a mock preview | DET-assist, JUDG verdict | any match AND JUDG finds no real changelog/docs surface | MEDIUM | Remove; this is CLI-fixture flavor with nothing to say to a visitor (delete) |
| SLOP-045 | Decorative identical stat/KPI columns | DET-assist, JUDG verdict | ≥ 4 same-shape stat siblings (≥ 3 beside a marketing CTA), AND JUDG finds KPIs were not requested or a figure has no real source | MEDIUM once JUDG confirms (tier Inferred, MD-011's JUDG posture); a DET-assist hit alone is a review candidate, since an accurate stats banner is a legitimate pattern until judged otherwise | Remove unless the brief actually asked for KPI display, and back any kept number with a real source (delete) |
| SLOP-046 | Decorative gauge/sparkline/progress element with a hard-coded value | DET-assist, JUDG verdict | candidate present, AND JUDG finds no real data point behind it | MEDIUM | Remove unless it encodes a real, current data point (delete) |
| SLOP-047 | Illegible ticker-scale logo wall | DET | distinct-logo count ≤ 6, AND median rendered logo height < 20px at the 1440px RS viewport. The 20px floor is a house default: the corpus names the failure ('unreadable mosquito logos') without a size, and neither reference clone publishes one; recalibrate on labeled logo walls before tightening | MEDIUM | Slow it down, enlarge the logos, or replace the loop with a static row if the count is this small (correct) |
| SLOP-048 | Autoplay carousel dots with no real function | DET | candidate present, autoplay declared or observed, and none of the accessible-binding signals present | LOW | Remove the dots or wire them to real keyboard/AT-reachable navigation (correct) |
| SLOP-049 | Generic silhouette/egg avatar standing in for a person | DET | match against the fixed list | LOW | Use a believable photo placeholder or a deliberate illustrated style instead (correct) |
| SLOP-050 | Category label printed under every logo in a trust wall | DET | any match | LOW | Drop the caption; the logo alone carries the credibility (delete) |
| SLOP-051 | Illustration assembled from an excessive primitive count | JUDG, DET-assist | all DET-assist conditions met (≥ 8 primitives, ≥ 200×200px, ≥ 3 fills, ≤ 2 text elements, no pattern) AND JUDG confirms a stand-in scene. The constants are impeccable's published ones (it reads declared width/height or viewBox; this row reads the rendered box), not yet calibrated on this family's pages | MEDIUM | Commission or simplify the illustration; don't primitive-stack a substitute (correct) |
| SLOP-052 | Busy geometric mask faking a photographic edge | DET | polygon: ≥ 10 vertices and mostly off-grid; path(): ≥ 3 curve segments (impeccable's published constants) | LOW | Use a real photographic crop, or a simple deliberate shape (correct) |
| SLOP-053 | Emoji glyphs standing in for a real icon set | DET-assist, JUDG verdict | any match AND JUDG finds no stated emoji-policy exception | LOW | Replace with the project's chosen icon set (correct) |
| SLOP-054 | Hover transform applied to the image element itself | DET | rule targets the image node itself | LOW | Move the transform to the container; animate the frame, not the picture (correct) |
| SLOP-055 | Recurring cluster of generic tells appearing together | JUDG | ≥ 2 co-occurring DET hits on one component escalates the row from WARN to a real finding | MEDIUM (escalated); LOW (WARN) below that | Break up the combination; vary the visual language for that component specifically (correct) |
| SLOP-056 | Overall "could be any competitor's product" genericness | JUDG | — | LOW (WARN), holistic-only | No single fix; return to the specific rows above that are contributing to the impression and act on those (correct) |
| SLOP-057 | Broken image source | DET | any match | HIGH | Fix or replace the source, or remove the element (correct / delete) |
| SLOP-058 | Dead link | DET (derived — an attribute scan cannot see an attached handler) | any match | HIGH (nav/primary) / MEDIUM (decorative) | Point it at a real destination, or make it a real button if it has no destination (correct) |
| SLOP-059 | Button with no type/handler inside a form | DET inside a form; JUDG outside one | missing type on a button whose form owner has ≥2 submit-capable buttons (a lone typeless button is the intended implicit submit) | HIGH (inside a form only) | Add an explicit type="button" (or "submit" when that is genuinely intended) (correct) |
