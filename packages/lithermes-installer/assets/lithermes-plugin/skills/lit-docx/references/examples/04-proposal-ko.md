::: cover variant=typographic kicker="사업 제안서"
지하철역 두 곳과 산업단지를 잇는 공동 통근버스 4개 노선을 2027년 3월부터 6개월 동안 시범 운행하자는 제안이다.
:::

# 제안 개요

예시 산업단지에는 42개 기업, 직원 약 6,800명이 일한다. 가장 가까운 지하철역까지 3km가 넘어, 2026년 9월 설문에서 직원의 71%가 자가용으로 출근한다고 답했다. 출근 시간대 진입로 정체는 평균 25분이다.

::: keyfigures
- **하루 1,200명** 통근버스 이용 목표 (예시)
  - 2026년 9월 설문의 이용 의향 비율을 전체 직원 수에 적용
- **8%p** 자가용 출근 비율 감소 목표 (예시)
  - 71%에서 63%로, 시범 마지막 달 설문 기준
- **약 3.8만 원** 이용자 1인당 월 기업 부담 (예시)
  - 기업 분담금 2.73억 원을 6개월과 하루 이용 목표로 나눈 값
:::

공동 노선이면 자체 버스가 없는 작은 기업 직원도 탈 수 있다.

::: callout kind=key title="결정 요청"
2026년 12월 총회에서 시범 사업비 3.9억 원(예시) 가운데 기업 분담분 2.73억 원의 분담 기준과 2027년 3월 운행 시작을 승인해 주기를 요청한다.
:::

# 현황

표 1. 출근 수단별 비중 (2026년 9월 설문, 예시)

| 출근 수단 | 응답자 (명) | 비중 (%) |
| --- | ---: | ---: |
| 자가용 | 1,669 | 71.0 |
| 기업 자체 통근버스 | 270 | 11.5 |
| 시내버스 | 230 | 9.8 |
| 기타 | 181 | 7.7 |
| 합계 | 2,350 | 100.0 |

자료: 입주기업협의회 출퇴근 실태 설문

주차면은 약 3,600면인데 평일 오전 주차 차량은 4,100대 안팎이다. 남는 차량은 진입로와 이면 도로에 서서 화물차 진입을 늦춘다.

# 운행 계획

45인승 버스 8대가 출퇴근 시간에 4개 노선을 노선마다 하루 16회씩 다닌다. 하루 2,880석으로, 이용 목표 1,200명의 왕복 승차 2,400회를 받을 수 있다.

# 예산과 일정

표 2. 시범 사업비 내역 (6개월, 예시)

| 항목 | 내용 | 금액 (만 원) |
| --- | --- | ---: |
| 버스 임차 | 45인승 8대, 대당 월 650만 원 | 31,200 |
| 정류장 시설 | 표지판, 대기 쉼터 4곳 | 2,400 |
| 승차 확인 | 단말기 8대, 앱 기능 | 1,800 |
| 운영 관리 | 전담 인력 1명 | 2,100 |
| 홍보와 예비비 | 설명회, 노선 조정 대비 | 1,500 |
| 합계 |  | 39,000 |

주: 기업 분담 70%(2.73억 원), 시 지원금 30%(1.17억 원)로 가정한 예시이며, 부가가치세를 포함한다.

표 3. 추진 일정 (예시)

| 시기 | 할 일 | 담당 |
| --- | --- | --- |
| 2026년 12월 | 협의회 총회 승인, 시 지원금 신청 | 사무국 |
| 2027년 2월 | 정류장 설치, 승차 앱 배포 | 사무국, 운수 업체 |
| 2027년 3월 | 시범 운행 시작 | 운수 업체 |
| 2027년 8월 | 결과 보고, 정식 운행 여부 결정 | 사무국 |

가장 큰 위험은 시 지원금이 늦게 확정되는 경우다. 결정이 2월을 넘기면 첫 달은 4대로 두 노선만 운행한다.
