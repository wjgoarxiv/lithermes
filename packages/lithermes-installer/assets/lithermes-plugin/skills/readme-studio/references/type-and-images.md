# Image inputs and shaped lettering

Inspect native Hermes capability in the actual session. Tool names alone do not prove an authenticated generation succeeded. Save the real returned image to the authorized output root, inspect it visually and record the request, tool identity, output hash and dimensions. Generate an original text-free field so deterministic composition controls exact lettering. If unavailable, report `IMAGE_GENERATION_UNAVAILABLE` without login, API-key request or cross-host fallback. After an explicit supplied image arrives, inspect and record it as supplied; do not claim it was generated by Hermes. Continue facts independently while waiting for the input.

Do not load untrusted active SVG into a browser. Require a trusted locally authored vector, or review/normalize scripts, event handlers, external references and embedded active content before consumption. The supplied raster background and outlined type form a hybrid cover, not a wholly vector illustration. Preserve an original copy and choose a crop with enough quiet space for lettering.

Use Pretendard for Korean/display/prose and Meslo LGS NF for technical labels. Fonts must have explicit regular-file paths, bounded sizes and inspected redistribution licenses. Resolve identity from the font metadata; filename alone is insufficient. No OS font install occurs. Keep license notices with task assets and omit font binaries from deliverables unless the license permits them. No silent substitution: unavailable type yields `FONT_INPUT_UNAVAILABLE` and the exact needed file/notice.

Copy `templates/typography/` from the exact selected skill directory to a fresh task workspace, then run `npm ci --ignore-scripts` there. The helper uses pinned fontkit for shaping, glyph advances, offsets and real outline bounds. It rejects missing glyphs, malformed text, unsafe fill values, symlinked inputs/parents and existing outputs. Whitespace advances the pen but does not create fake outline bounds. Example from that copied directory, with an existing output directory:

```sh
node outline.mjs --font "/explicit/fonts/Pretendard-Bold.otf" --license "/explicit/fonts/OFL.txt" --family Pretendard --text "연구 기록" --fill '#111d25' --output-root "/task/cover/assets" --output "title-dark-ink.svg"
```

Create the matching `title-light-ink.svg` with fill `#f4f1e9`; repeat for subtitle and Meslo technical label. These suffixes specify INK, not theme. Light field `#f4f1e9` selects dark ink `#111d25`; dark field selects light ink. Use the same mapping for stills and movies and check at least 4.5:1. Preserve JSON stdout with family/PostScript name, font/license SHA-256, exact source string, glyph count and output geometry. This confirms inputs and shaping, not legal review of the notice. Keep editable strings in `cover-source.json`.

Inspect Korean shaping, spacing, ligatures, baseline and actual SVG paths; no `<text>`, external font reference or fallback glyph may remain. Render the SVG on both intended fields before composition. Use a limited integer-grid original pixel motif, Gaussian background blur, static seeded grain, a soft lighting gradient and slight depth motion. Effects never blur or wash out lettering. Offer restrained or expressive treatment only when useful; four basic theme/size outputs already cover the necessary delivery cases.
