# 자동 핸드오프

[← README로 돌아가기](../README_Ko-KR.md) · [English](./automatic-handoff.md)

긴 세션은 모델의 컨텍스트 창을 채우고, 창이 차면 Hermes가 대화를 압축하면서 오래된 세부 내용이 사라집니다. 자동 핸드오프는 그 전에 모델이 핸드오프를 쓰게 하고, 압축이 끝나면 그 내용을 다시 불러옵니다. 기본값은 꺼짐이고, 퍼센트는 직접 정합니다. LitHermes에는 내장 기본값이 없습니다.

세션 안에서 원하는 퍼센트로 켜세요.

```
/lit-handoff auto on 60
```

이후 모델 호출 한 번이 컨텍스트 창의 60%를 넘게 쓰면, 다음 메시지에 lit-handoff 절차로 핸드오프를 쓰라는 짧은 요청이 붙습니다. 모델은 파일을 저장하고 한 줄로 알려 줍니다. `Handoff saved. Run /compact now.` (Hermes 0.17에서는 명령이 `/compress`입니다.) 압축한 뒤 첫 메시지에는 그 핸드오프의 요약이 붙어서, 작업이 멈춘 곳에서 이어집니다.

Hermes에서 플러그인이 할 수 있는 일은 지켜보고 요청하는 것까지이고, 압축은 사용자나 Hermes만 시작할 수 있습니다. 네 단계와 각 단계를 맡는 쪽은 다음과 같습니다.

| 단계 | Hermes에서 맡는 쪽 |
|---|---|
| 컨텍스트가 얼마나 찼는지 재기 | 자동입니다. LitHermes가 모델 호출마다 토큰 수를 읽습니다. |
| 모델에게 핸드오프 요청하기 | 퍼센트를 넘긴 뒤 첫 메시지에 자동으로 요청합니다. 요청을 따르는 것은 모델의 몫입니다. |
| 대화 압축하기 | 사용자가 `/compact`를 실행하거나 Hermes가 자체 기준으로 압축합니다. Hermes에서는 플러그인이 압축을 시작할 수 없습니다. |
| 핸드오프 다시 불러오기 | 압축 뒤 첫 메시지에 자동으로 불러옵니다. 이 세션의 ID가 들어 있고 요청 뒤에 쓴 파일만 불러오며, 그런 파일이 없으면 불러올 것이 없었다고 알려 줍니다. |

설정은 다음 스위치로 합니다.

- `/lit-handoff auto on <percent>`는 1에서 99 사이의 정수 퍼센트로 켭니다. 숫자를 빼면 마지막으로 고른 값을 다시 쓰고, 고른 적이 없으면 숫자를 물어봅니다.
- `/lit-handoff auto off`는 끄고, 다음에 켤 때를 위해 퍼센트를 기억해 둡니다.
- `/lit-handoff auto status`는 켜져 있는지, 이 세션의 최근 측정값, Hermes 자체 압축 시점과의 비교를 보여 줍니다.
- `LITHERMES_AUTO_HANDOFF=1`과 `LITHERMES_AUTO_HANDOFF_PERCENT=60`을 함께 설정하면 Hermes를 실행하는 환경에서 같은 설정을 할 수 있어, 셸 프로필에 넣기 좋습니다. 환경 변수가 명령보다 우선합니다. 앞의 변수가 `1`이 아닌 값이면 꺼진 채로 있고, 퍼센트가 1에서 99 사이의 정수가 아니어도 꺼진 채로 있으며 `hermes lithermes doctor`에 경고가 뜹니다.

퍼센트는 Hermes가 스스로 압축하는 시점보다 낮게 고르세요. 최신 Hermes에서는 기본값이 창의 절반쯤이고, 512K 토큰보다 작은 창에서는 75%로 올라가며, Hermes 설정에 상한이 있으면 고정 토큰 수로 내려갑니다. 고른 퍼센트가 그 시점과 같거나 높으면 Hermes가 먼저 압축해서 핸드오프가 쓰이지 않습니다. `hermes lithermes doctor`와 `/lit-handoff auto status`가 둘을 비교해서 경고합니다.

요청은 퍼센트를 넘을 때마다 한 번만 나가고, 도구를 실행하는 중이나 도우미 에이전트에게는 가지 않습니다. LitHermes가 저장하는 것은 스위치와 마지막 퍼센트뿐이며, Hermes 홈의 `lithermes` 폴더에 들어갑니다. 핸드오프 자체는 프로젝트의 평소 `HANDOFF.md`(또는 `.handoff/HANDOFF.md`)입니다.
